# 0.5.0 — 2026-11-21

## Added

- **Historical Area Tables** can be selected with `as_of_date` in coverage summaries, area comparisons, and underserved rankings. `fcc_list_filing_periods` marks the ten supported filings from December 2016 through June 2021 ([#47](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/47)).

## Changed

- FCC HTTP errors now omit `structuredContent.error.data.body` and `structuredContent.error.data.responseBody`.
- **Development and packaging checks** validate CLI flags, preserve executable SDK skills in desktop bundles, and check the published skill tree and release annotation.

## Fixed

- **Block provider identity** labels `providerId` as the Form 477 filing number and returns optional `frn` and `dbaName`. Existing mirrors fetch and cache available identity fields when those offerings are read ([#45](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/45)).
- **Mirror verification** reports the provider dimension as `derived` and describes which data the listed states and full-corpus marker cover ([#39](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/39)).
