# 0.1.13 — 2026-08-13

## Added

- **Community and license files** — `LICENSE` (Apache-2.0), `.gitattributes`, `.github/CODE_OF_CONDUCT.md`, `.github/CONTRIBUTING.md`, `.github/SECURITY.md`.
- **Supply-chain install guard** — `bunfig.toml` sets `minimumReleaseAge` (3 days) to hold back freshly published package versions, excluding `@cyanheads/mcp-ts-core` for same-day framework adoption; installs are also scanned by `@socketsecurity/bun-security-scanner`.

## Changed

- **Form 477 mirror query ceilings** ([#19](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/19)) — `createForm477Stores` now declares a `limits.limit` ceiling on all five store specs (50,000 for deployment/area/geography, 2,000 for the provider-search FTS store, 1,000 for provider summary), and `form477-mirror.ts` imports the same constants at its call sites. A read past a store's ceiling now fails with a typed `ValidationError` naming the bound instead of executing unbounded.
- **`@cyanheads/mcp-ts-core`** `^0.10.10 → ^0.11.5` (pulls in `@modelcontextprotocol/sdk` ^1.30.0).
- **`tsconfig.json`/`tsconfig.build.json` split** — the root config now type-checks `src/` and `tests/` (`noEmit: true`); the build config emits from `src/` only.
- **Dockerfile** — pinned `oven/bun` image tags to `1.3.14`, added BuildKit cache mounts on the install layers, and production installs now pass `--omit=peer` so mcp-ts-core's optional peer tiers and this server's optional `better-sqlite3` peer stay out of the runtime image.
- **`.mcpb` bundle strip** — `scripts/clean-mcpb.ts` now also removes `@duckdb/node-bindings-*` platform-specific native binaries alongside the existing agent-doc strip, keeping bundles cross-platform and under the registry size cap; checked by `lint:packaging`.
- `devcheck`'s outdated-package check no longer flags a row held by `minimumReleaseAge` or a `peerDependency` floor as a finding — it fails only on packages actually behind their declared range.
- `scripts/`, `docs/tree.md`, and 21 vendored skills re-synced to the current framework templates; `.github/FUNDING.yml` trimmed to the two active platforms; `.gitignore`'s `data/` entry root-anchored to `/data/`.
