# 0.1.10 — 2026-07-02

## Added

- **`invalid_geography_id_shape`** — `fcc_get_coverage_summary` and `fcc_compare_areas` now fail fast when a GEOID's digit count doesn't match its `geography_type` (state=2, county=5, cd=4, cbsa=5, place=7), before any upstream call. A county FIPS passed as `geography_type="state"` gets a targeted cross-hint naming the 2-digit prefix. `nation` and `tribal` are deliberately unvalidated. Shared `GEOID_DIGIT_LENGTHS` table + `geoidShapeError()` in `src/services/open-data/types.ts`. [#13](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/13)
- **`OpenDataService.getGeographyNames()`** — batched GEOID→name resolution against the geography lookup dataset (single `geoid IN (...)` query). `fcc_find_underserved` and `fcc_compare_areas` rows gain an optional `name` output field, and the format tables render a `Name (GEOID)` column; a resolution failure never fails the call. [#12](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/12)

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.10.9 → ^0.10.10`.

## Fixed

- **README** — the `fcc-broadband://providers/list` resource row no longer claims the list includes company names; it returns `hoconum` identifiers only, with `fcc_search_providers` as the name-resolution path. [#5](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/5)
