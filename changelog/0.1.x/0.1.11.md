# 0.1.11 — 2026-07-02

## Added

- **Local Form 477 mirror** ([#8](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/8)) — opt-in SQLite mirror of the frozen Form 477 corpus (June 2021 was the last filing period), built on the framework's `@cyanheads/mcp-ts-core/mirror` module. New `src/services/open-data/mirror/` holds the stores, ingest pipeline, and `Form477Mirror` read facade.
- **`FCC_MIRROR_ENABLED` / `FCC_MIRROR_PATH`** env vars (off by default; path defaults to `data/fcc-mirror`) — wired through `server-config.ts`, `.env.example`, `server.json`, and `manifest.json`.
- **`mirror:init`** script — one-time bootstrap paging the Socrata CSV export (`$limit=50000`, `$order=:id`). State-scoped (`--states 11,53`) or full-corpus (`--full`, ~9 GB / hours-scale); idempotent and resumable via persisted cursors, with already-covered states skipped.
- **`mirror:verify`** script — per-store sync state, row counts, SQLite integrity checks, and the coverage roster.
- **Coverage-gated serving** — state-scopable reads (`fcc_search_availability`, `fcc_get_coverage_summary`, `fcc_compare_areas`, `fcc_find_underserved`, geography names) serve from the mirror when the queried state is fully ingested; cross-state aggregations (`fcc_search_providers`, `fcc_get_provider`) and geography types without an embedded state (cbsa/tribal/nation) require the full-corpus marker. Anything uncovered — and any mirror-layer error — falls back silently to the live Socrata API.
- **Provider dimension** — distinct `hoconum × holdingcompanyname × stateabbr × techcode` table derived during deployment ingest, with FTS5 over the holding-company name. `fcc_search_providers` uses word-prefix matching on the mirror (`comc` matches "Comcast") rather than the live API's arbitrary-substring match.
- **`better-sqlite3`** `^12.0.0` as an optional peer dependency for the Node.js runtime; under Bun the mirror uses the built-in `bun:sqlite`.
- **Tests** — `tests/services/open-data/` covers mirror routing (coverage gates, live fallback, disabled passthrough, provider aggregation gating) and the CSV/FTS/GEOID-range helpers.

## Changed

- **`Dockerfile`** — ships the mirror lifecycle scripts and a writable `data/` directory so the opt-in bootstrap works in-container (`docker exec <ctr> bun run mirror:init -- --states ...`); dependency install uses `--ignore-scripts` so the optional `better-sqlite3` native addon is never compiled into the Bun-only image.
- **README** — mirror bootstrap/serving-rules section and config-table rows for the new env vars.
