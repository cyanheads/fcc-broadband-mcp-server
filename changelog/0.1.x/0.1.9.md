# 0.1.9 — 2026-06-20

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.10.6 → ^0.10.9`. User-relevant deltas:
  - **`ctx.content`** — new always-present collector for non-text content blocks (image/audio bytes); `ctx.content.image()` / `.audio()` push base64 media into `content[]` without it leaking into `structuredContent`.
  - **Canvas SQL gate** — a `SELECT`-shaped statement that parses but fails to prepare (mistyped column, unknown function) now throws `ValidationError` with `data.reason: 'invalid_sql'` and the DuckDB binder detail, instead of misreporting `non_select_statement`.
  - **`DuckdbProvider.describe({ tableName })`** — qualified the pushed `WHERE` filters, fixing an ambiguous-column Binder Error on every filtered `describe()`.
  - **Fresh-scaffold devcheck guards** — changelog-sync and the git-dependent checks (TODOs, Tracked Secrets, Framework Antipatterns) now skip cleanly when `.git` is absent rather than failing.
- **`devcheck` toolchain** synced to 0.10.9 — adds two static checks: `check-dependency-specifiers` (hard-fails on floating `latest`/`*`/dist-tag specifiers in `package.json` and the `bun.lock` workspace map) and plugin-manifest validation in `lint:packaging` (descriptions, unscoped display names, full-name install args for `.claude-plugin` / `.codex-plugin` manifests).
- **`devcheck.config.json`** — added `packaging.pluginManifests: true` to enable the new plugin-manifest checks.
- **Vendored skills** re-synced to mcp-ts-core 0.10.9.
