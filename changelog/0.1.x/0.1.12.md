# 0.1.12 — 2026-07-02

## Changed

- **Live name-search `$limit`** — grouped provider queries with `nameSearch` drop the 10x grouped-row headroom (`min(limit,200)*10` → `min(limit,200)`); Socrata's GROUP BY short-circuits at the smaller limit and stays inside the 30s budget. Tradeoff on the live path (mirror not fully ingested): a broad no-state name search returns at most `limit` grouped rows, so `statesServed`/`techCodes` can be partial for multi-state providers. The mirror path keeps full fidelity.

## Fixed

- **Retry amplification on deterministic timeouts** ([#14](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/14)) — `OpenDataService.fetchJson` now classifies a 30s deadline abort into `McpError(Timeout)` at the fetch choke point instead of letting the raw `AbortError` pass `withRetry`'s always-transient default. Cheap point queries keep transient retries; the grouped provider search passes a `retryable: false` factory so it fails once, fast, instead of 4 attempts (~2min wall clock).
- **`live_search_timeout`** — new non-retryable `errors[]` contract entry on `fcc_search_providers` (`JsonRpcErrorCode.Timeout`) with a recovery hint: add a `state` filter, use a longer name fragment, or enable the local Form 477 mirror (`FCC_MIRROR_ENABLED=true`).
