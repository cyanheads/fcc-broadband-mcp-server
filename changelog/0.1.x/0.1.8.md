# 0.1.8 — 2026-06-12

## Added

- **`fcc_find_underserved`**, **`fcc_search_providers`**: truncation enrichment — when more areas/providers match than the `limit` returns, `ctx.enrich.truncated()` reports `truncated`, `shown`, and `cap` so agents know the result set was capped.
- **`FCC_BDC_USERNAME`**, **`FCC_BDC_HASH_VALUE`**, **`FCC_OPENDATA_APP_TOKEN`**: optional credential env vars now advertised in `server.json` (registry discovery) and `manifest.json` (bundle install UX). All `isRequired: false` — Form 477 tools stay keyless; BDC tools and higher Open Data rate limits opt in.
- **`scripts/clean-mcpb.ts`**: post-pack bundle cleaner — runs `mcpb clean`, then strips dependency-shipped agent docs (`node_modules/**/skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach, and asserts zero remain. Wired into the `bundle` script.
- **Docker `HEALTHCHECK`**: bun-native `fetch` against `/healthz` (the slim runtime image ships no curl/wget); `org.opencontainers.image.version` label fed by the `APP_VERSION` build arg.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.21 → ^0.10.6`.
- **`createApp()`**: explicit `name`/`title` set to `fcc-broadband-mcp-server` — the served identity is the unscoped machine name on every surface, not the scoped npm name.
- **`scripts/lint-packaging.ts`**: bundle-content guards (checks 5–8) reject unanchored `.mcpbignore` dev-dir patterns that strip runtime `node_modules` paths and verify a built `.mcpb` carries no agent-doc entries; identity check (9) asserts `createApp()` `name`/`title` and manifest `display_name` equal the unscoped package name.
- **`scripts/check-framework-antipatterns.ts`**: new rule flags `z.coerce.boolean()` on env flags (`Boolean("false")` is `true`) in favor of `z.stringbool()`; comment lines are skipped so documentation naming the pattern doesn't false-positive.
- **`.mcpbignore`**: root dev-dir patterns anchored with a leading `/` so they no longer also strip nested runtime paths under `node_modules`.
- **Vendored skills** synced to mcp-ts-core 0.10.6 (adds `skills/techniques/`).

## Dependencies
