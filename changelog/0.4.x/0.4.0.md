# 0.4.0 — 2026-11-03

## Added

- Add a broadband-analysis guide served as an MCP skill resource.
- **Geography discovery** supports state, county, congressional district and tribal names alongside place and CBSA searches ([#46](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/46)).
- **Result continuation** adds offset/nextOffset to underserved rankings and provider searches; full mirrors traverse every matching provider dimension row before company pagination, while live searches retain sampling disclosures ([#44](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/44)).

## Changed

- **Area technology filters** accept all 63 canonical combinations and default to satellite-excluding acfow; speed descriptions specify download/upload pairs and historical population limits. The summary resource retains satellite-inclusive acfosw at 25/3 Mbps ([#40](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/40)).
- **Area comparisons** query up to 300 distinct IDs in batches, rank globally, and disclose duplicate, unmatched and excluded IDs ([#42](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/42)).
- **Packaging and development tooling** add Agent Plugins metadata, ship the guide across distribution formats, preserve executable SDK skills in desktop bundles, and sync validation and development guidance.

## Fixed

- **Empty demographic segments** return zero population with a notice only after confirming geography rows exist; required coverage reads share a 48-second deadline ([#41](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/41)).
- **Geography names** use the live 2021 lookup even with an existing yearless mirror; unavailable optional names preserve coverage metrics and caller cancellation propagates ([#43](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/43)).
- **Provider state validation** rejects unknown USPS codes before querying and preserves states, DC and inhabited territories ([#48](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/48)).
