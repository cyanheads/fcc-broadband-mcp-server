# 0.2.0 — 2026-08-13

## Changed

- **Breaking: `fcc-broadband://providers/list` is now the paged template `fcc-broadband://providers/list/{offset}`** ([#26](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/26)) — replaces the single unpaginated, name-less payload with 25-entry pages carrying `holdingCompanyName` alongside each `hoconum`, plus the directory's `total`. The old bare URI no longer resolves: read `fcc-broadband://providers/list/0` for the first page and follow each response's `nextOffset` to continue.

## Fixed

- **`fcc_get_provider` no longer times out on a valid `hoconum`** ([#29](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/29)) — replaces two `GROUP BY` scans over the 78M-row deployment table with indexed point queries.
- **`fcc_get_provider`'s `hoconum` input rejects non-digit values before querying upstream** ([#16](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/16)) — previously reached FCC Open Data unvalidated and came back as a raw upstream error.
- **`fcc_get_provider`'s population figures are no longer overcounted** ([#21](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/21)) — `speedTierLocations` (now `speedTierPopulation`) summed the FCC's overlapping technology roll-ups on top of the individual rows; for Comcast the summed total ran 3x the FCC's own `tech='all'` figure. It now reads that row alone, and three `d_5`–`d_7` tier labels are corrected from 50/100/250 to 100/250/500 Mbps.
- **`fcc_search_providers` no longer times out on a name search** ([#18](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/18)) — replaces the grouped query with a bounded 1,000-row unordered window, deduplicated in process. `scanTruncated`/`scanRowCap` mark a sample result; `totalCount` is present only on a complete scan.
- **`fcc_search_providers` no longer understates a matched company's footprint** — `statesServed`/`techCodes` were read off the same window rows used to find matches, which sample a large carrier's blocks far more thinly than its states or technologies; each returned company's footprint is now resolved with its own lookup.
