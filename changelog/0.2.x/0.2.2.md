# 0.2.2 — 2026-08-25

Maintenance release on [@cyanheads/mcp-ts-core](https://www.npmjs.com/package/@cyanheads/mcp-ts-core) `^0.11.5 → ^0.12.3`. No tool's declared input or output contract changed, so no correct client needs a code change to upgrade — but a caller sending an argument key the schema never declared is now rejected rather than ignored.

## Added

- **`cacheHints` in `src/index.ts`** declares what a client may reuse per operation: one hour for `tools/list`, `prompts/list`, `resources/list`, `resources/templates/list`, and `server/discover`; 24 hours for `resources/read`, since both resources read Form 477, closed as of the June 2021 filing period. Scope is `public` — no definition declares an auth scope, so every caller is served the same listing. Applies on protocol revision 2026-07-28 only.
- **`tests/tools/strict-inputs.test.ts`** asserts across all nine tools that the minimal declared arguments parse, an undeclared key is rejected by name, and the advertised `inputSchema` carries `additionalProperties: false`. The suite is 399 tests, up from 371.

## Changed

- **Protocol revision 2026-07-28 is served on the HTTP endpoint**, alongside the 2025-era revisions.
- **Tool inputs are strict** — an undeclared argument key is rejected by name instead of being silently ignored, so a misspelled key surfaces as an error rather than a quietly wrong answer.
- **The advertised `outputSchema` declares the error envelope**, and advertised JSON Schema is 2020-12 rather than draft-07. A strict 2020-12 client no longer rejects a tool before dispatching it.
- **Input-validation failures read as flat `path: message` sentences** rather than a serialized issue blob.
- **`ctx.log` output also reaches the client** as `notifications/message`, gated by the client's `logging/setLevel`.
- **`resources/subscribe` is supported** — `fcc-broadband://geography/{type}/{id}/summary` and `fcc-broadband://providers/list/{offset}` accept subscriptions.
- **`.env.example` sets `MCP_SESSION_MODE=stateless` explicitly**, matching the `Dockerfile`. The comment now names all three accepted values and that the `auto` default resolves to stateful. `MCP_HTTP_RESUMABILITY`, `MCP_HTTP_RESUMABILITY_MAX_EVENTS`, `MCP_HTTP_RESUMABILITY_TTL_MS`, `MCP_LOG_RATE_LIMIT_THRESHOLD`, and `MCP_LOG_RATE_LIMIT_WINDOW_MS` are documented for the first time.
- **Bun pins move to 1.4.0** — the `Dockerfile` build and `-slim` production stages, plus `packageManager`. `engines.bun` stays `>=1.3.0`, and the build stage now carries `--platform=$BUILDPLATFORM`, so it runs on the builder's own architecture instead of being emulated once per target.
- **`scripts/lint-mcp.ts` drops its `taskHandlers` branch** and `scripts/lint-packaging.ts` tracks `@modelcontextprotocol/server` in place of `@modelcontextprotocol/sdk`, following the removal of the experimental tasks surface and the SDK package rename. The README MCP SDK badge reads `^2.0.0`.
- Resynced framework scripts and 19 shipped skills.
