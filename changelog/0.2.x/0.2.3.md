# 0.2.3 — 2026-09-20

Maintenance release on [@cyanheads/mcp-ts-core](https://www.npmjs.com/package/@cyanheads/mcp-ts-core) `^0.12.3 → ^0.13.6`, plus the framework's skill-tree relocation and plugin-manifest packaging updates.

## Added

- **`sessionMode: 'stateless'`** declared in `src/index.ts`, and a `teardown` hook (`closeOpenDataService`) that releases the Form 477 mirror's SQLite handles on shutdown — the one resource this server holds past a single request.
- **`tests/tools/input-pipeline.test.ts`**, **`tests/config/server-config.test.ts`**, **`tests/services/open-data/open-data-service-shutdown.test.ts`**, and **`tests/services/upstream-error-redaction.test.ts`** pin the argument pipeline, env normalization, teardown, and error-data redaction below. Suite is 447 tests, up from 399.

## Changed

- **An argument key the schema never declared is dropped or rewritten before rejection, not rejected outright** — a client-added bookkeeping key (e.g. `_meta`) is dropped, a camelCase spelling of a declared key (`geographyType`) is rewritten to the canonical name, and a JSON-stringified array is repaired and re-parsed once after a failed parse. A key that is still unrecognized after all three stages is rejected as before.
- **An argument rejection classifies `InvalidParams` (-32602), not `ValidationError` (-32007)** — carries `data.reason: "invalid_arguments"` and a schema-derived recovery hint; `content[]` closes with `Recovery: …` and `(reason invalid_arguments)`. A handler-thrown contract error keeps its own declared code, and now closes with `(reason <reason> · not retryable)` when the entry carries a reason or a `retryable` flag.
- **Upstream error data no longer carries the request URL by default** — the Socrata app token (Open Data queries) and the BDC credential hash no longer reach a caller's `error.data` on a non-2xx response.
- **A blank or unsubstituted `${user_config.…}` credential reads as absent, not as a literal string** — `FCC_BDC_USERNAME`, `FCC_BDC_HASH_VALUE`, and `FCC_OPENDATA_APP_TOKEN` previously had no local guard, so an operator who left one unset in a bundle or plugin install got the placeholder text itself as the credential value. `mirrorPath`'s local blank/whitespace guard is replaced by the same framework-wide normalization, which additionally now catches an unsubstituted placeholder it didn't before.
- **`fcc_find_underserved` and `fcc_search_providers` no longer advertise a not-found error** — an empty match was already returned as a successful ranking or list carrying a notice, so the declarations were never thrown; the new unthrown-reason lint caught the dead entries. `thrownBy: 'service'` marks the reasons `fcc_get_provider`, `fcc_list_downloads`, and `fcc_search_providers` raise from their service layer, lint-only metadata for the same rule.
- **Bun engines floor raised to `>=1.4.0`**, matching the version the Docker image has pinned since 0.2.2.
- **Skill tree relocated from `skills/` to `framework-skills/`** so a `.claude-plugin/`/`.codex-plugin/` install no longer hands these development skills to every installing agent, and resynced to the current upstream content, adding `release-pr-review`.
- **Every `FCC_*` variable is wired into both plugin manifests** — `.claude-plugin/plugin.json` declares each as a `userConfig` option, `.codex-plugin/mcp.json` lists them in `env_vars`, and `manifest.json` gives each a `"default": ""`.
