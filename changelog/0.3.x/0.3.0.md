# 0.3.0 — 2026-10-18

## Added

- **`fcc_search_geographies`** discovers place and CBSA GEOIDs by name, with literal substring matching and stable offset pagination against the 2021 FCC lookup ([#31](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/31)).
- **`test:coverage`** runs behavioral coverage checks for mirror ingestion, startup, prompts, and tool output against the existing thresholds ([#34](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/34)).

## Changed

- **BDC discovery** advertises `fcc_list_downloads` only when both parsed credentials are configured; its disabled landing card retains setup guidance ([#32](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/32)).
- **Desktop bundles** exclude source, tests, scripts, documentation, coverage, and editor configuration.
- **Framework guidance** syncs API references and release checks to `mcp-ts-core` 0.13.15.

## Fixed

- **`fcc_geocode_block`** retries structured FCC backend faults returned as HTTP 400 and reports `geo_backend_unavailable` with retry-later guidance ([#33](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/33)).
- **National coverage** resolves `United States` locally for tools and resources while preserving geography ID `0` ([#35](https://github.com/cyanheads/fcc-broadband-mcp-server/issues/35)).
